Module models 

Source
Expand description

Contains the data models for API requests and responses. Public request and response models grouped by wire protocol.

The module deliberately follows protocol boundaries instead of mirroring the implementation of any one gateway. Stable fields are typed; provider extensions and genuinely open JSON shapes are preserved in explicit serde_json::Value fields or extension maps.
